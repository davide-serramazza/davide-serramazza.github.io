Featured Project: tsCaptum

XAI Library for Time Series Classification

Live on PyPI

Problem: Standard XAI tools (like Captum) are not optimized for time-series data and are computationally slow.
Solution: Built tsCaptum, a Python library that bridges Captum with time-series frameworks (aeon, sktime), reducing computation time by 1-2 orders of magnitude.
Tech stack: Python, PyTorch, Captum, aeon, pytest.

Featured Project: drXAI framework

XAI Library for Time Series Classification

Problem: State of the art for Multivariate Time Series Classifications doesn't scale well with increasing number of channels and time points.
Solution: Built drXAI, a Python framework that selects features (either channels or timepoints) into Multivariate Time Series leveraging on saliency maps. It reduces 80–90% of the data while preserving accuracy.
Tech stack: Python, PyTorch, Captum, tsCaptum.
